HOWTO: Build an IFM Docker image
================================
1) To build a Docker image run the 'build-docker-image.sh' bash script.

2) This script requires two parameters GIT_USERNAME and GIT_ACCESS_TOKEN.

3) Replace the text in between the angular braces <...> with your username on
gitlab.stfc.ac.uk and your Personal Access Token on gitlab.stfc.ac.uk.

4) Run the 'build-docker-image.sh' from the terminal.
